# Unduh Bends-Daffo — Bedrock 26.50

- [Unduh add-on .mcaddon](Bends-Daffo-1.0.0-Bedrock-26.50.mcaddon?raw=true)
- [Unduh source Blender dan panduan](Bends-Daffo-Blender-Source.zip?raw=true)

Buka file `.mcaddon` dengan Minecraft, aktifkan Behavior Pack dan Resource Pack
pada dunia yang sama. Di roda gigi resource pack, pilih mode sendi siku/lutut
untuk skin klasik Steve. Gunakan kamera orang ketiga dahulu. Peserta multiplayer
perlu menerima resource pack dunia; PvP/friendly fire diperlukan untuk reaksi
pukulan antar pemain.

Paket memuat 24 klip Blender untuk pukulan, lompat, menebang, renang, jalan/lari,
dan reaksi terkena pukulan/jatuh-bangkit. Pemain, zombie, husk, dan drowned dewasa
menjadi target dukungan. Source ZIP menyertakan `.blend`, exporter, kode, panduan
pemasangan, dan checklist pengujian dalam game.

**Status:** versi awal. 16 tes logika dengan API mock, pemeriksaan tipe/format
paket, dan perbandingan numerik ekspor Blender lulus. Belum diuji langsung di
Minecraft ataupun dua client multiplayer; kompatibilitas game belum terverifikasi.
Jatuh merupakan animasi visual, tanpa perubahan hitbox, penguncian kontrol,
atau simulasi ragdoll fisik. Detail batasan skin dan armor ada dalam panduan ZIP.

SHA-256 tersedia di `SHA256.json`. Ketentuan aset turunan Mojang dan lisensi
implementasi asli disertakan dalam paket serta source ZIP.
